Kiến trúc

  1. (a) Endogenous embedding — DINOv3: log-Mel 128×251 → ảnh 224×224 → ViT-S/16 → 14 token thời gian + CLS (global token).
  2. (b) Exogenous embedding: 13 biến ngoại sinh (giờ/thứ ghi âm, thời lượng, SNR, RMS, nguồn mic/upload, sample-rate, F0/energy/ZCR/centroid theo khung) → 13 variate token.
  3. (c) Self-Attention theo thời gian trên token nội sinh.
  4. (d) Cross-Attention: global token (query) ↔ variate token (key/value).
  5. Head: [global ‖ mean(patch)] → MLP → 5 nhóm tuổi.
